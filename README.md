## Protocole-666-Binary-Run
There is a robot in a binary run who don't look out binary code to decimal numbers on years. The robot is okay, but avoid the 666 number decimal or the robot will blow up! 

# Instructions
1. Be very fast and write an 10-digit binary code in 15 seconds.
2. Avoid the decimal number 666.
3. The 3 is not an instruction, only à date: If you translate a decimal number is less than 666, robot and text will become green, but if the decimal number is more than 666, the robot and text will become orange.But if decimal number is 666, all' will get red and the robot will blow up.
